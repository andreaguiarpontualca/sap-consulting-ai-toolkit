# SAP Consulting AI Toolkit

Este repositório centraliza prompts, templates, exemplos e padrões para utilização de Inteligência Artificial Generativa em atividades de Consultoria SAP.

O objetivo é transformar boas práticas individuais no uso de IA em ativos reutilizáveis e padronizados para toda a equipe, promovendo maior consistência, produtividade, rastreabilidade e segurança na produção de documentos e demais entregáveis.

O repositório contempla materiais para atividades como:

- revisão e elaboração de e-mails;
- atualização e detalhamento de chamados;
- apontamento de atividades;
- especificações funcionais;
- especificações técnicas;
- casos de teste funcionais;
- testes integrados;
- análise e revisão de documentos;
- padronização de prompts;
- governança de IA;
- materiais de treinamento.

A IA deve ser utilizada como ferramenta de apoio. Todo conteúdo produzido deve passar por validação do profissional responsável antes de ser utilizado como entregável oficial.
